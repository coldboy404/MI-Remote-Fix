# Archived build tools

These are the exact tool binaries used for this repair; SHA256SUMS is checked before building.

- Apktool 3.0.3: https://github.com/iBotPeaches/Apktool (Apache-2.0)
- Uber APK Signer 1.3.0: https://github.com/patrickfav/uber-apk-signer (Apache-2.0)
- dex2jar 2.4 and bundled dependencies: https://github.com/pxb1988/dex2jar (Apache-2.0; bundled dependency notices/licenses remain in JAR metadata)
- Android API34 android.jar and dx30.0.2: Android SDK / AOSP, https://source.android.com/

JDK17 is not bundled. Use JAVA_HOME or java/javac from PATH. Third-party binaries retain their upstream copyright and license terms.
